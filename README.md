# Pixel Dash Adventure

A moody jump-and-run platform game built with React, Vite, and custom pixel artwork.

## Run locally

```bash
npm install
npm run dev
```

## Controls

- A / D or Left / Right: move
- W, Space, or Up: jump
- R: restart
- On mobile, use the on-screen touch controls

Collect the nine sparks, avoid the patrolling enemies, and reach the beacon flag.
